# Module composdown-compose

Native Markdown rendering for Compose Multiplatform on Android, iOS and Desktop.

- [io.github.springmusk026.composdown.compose.Composdown] renders Markdown text, a parsed document,
  or a [io.github.springmusk026.composdown.compose.ComposdownState] whose text grows over time.
- [io.github.springmusk026.composdown.compose.composdownItems] renders a document's blocks as items
  of a lazy list.
- [io.github.springmusk026.composdown.compose.ComposdownDefaults] creates themes derived from
  Material 3; [io.github.springmusk026.composdown.compose.ComposdownComponents] replaces how any kind
  of block is drawn.
- [io.github.springmusk026.composdown.compose.ImageRenderer] and
  [io.github.springmusk026.composdown.compose.CodeHighlighter] plug in image loading and syntax
  highlighting.

# Package io.github.springmusk026.composdown.compose
