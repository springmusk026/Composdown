# Composdown

API reference for Composdown, complete and spec-compliant Markdown rendering for Compose
Multiplatform. Guides are in the [repository](https://github.com/springmusk026/Composdown#documentation).

| Module | Contents |
|---|---|
| `composdown-core` | Parser and document model |
| `composdown-compose` | Compose Multiplatform renderer |
| `composdown-coil` | Image loading with Coil |
| `composdown-highlight` | Code highlighting with Highlights |
