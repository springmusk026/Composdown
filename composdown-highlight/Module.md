# Module composdown-highlight

Syntax highlighting of code blocks with the pure Kotlin
[Highlights](https://github.com/SnipMeDev/Highlights) library.

Pass a [io.github.springmusk026.composdown.highlight.HighlightsCodeHighlighter] as the
`codeHighlighter` of `Composdown` or `composdownItems`.

# Package io.github.springmusk026.composdown.highlight
