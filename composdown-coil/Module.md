# Module composdown-coil

Image loading for Composdown with [Coil 3](https://coil-kt.github.io/coil/).

Pass a [io.github.springmusk026.composdown.coil.CoilImageRenderer] as the `imageRenderer` of
`Composdown` or `composdownItems`.
