## [Unreleased]

### Added

- Project structure: `composdown-core` and `composdown-compose` Kotlin Multiplatform modules targeting
  Android, iOS and Desktop (JVM).
- Build tooling: Gradle version catalog, convention plugins, Spotless (ktlint), detekt and binary
  compatibility validation (JVM and KLib).
- Continuous integration on Linux and macOS.
- `MarkdownParser`, a pure Kotlin CommonMark 0.31.2 parser producing an immutable document model
  (`MarkdownDocument`, `Block`, `Inline`) with structural equality. The 652 specification examples run
  as tests on every platform.
- `plainText()` to extract the text of inline content, for example for image descriptions.
- GitHub Flavored Markdown, enabled by default and selectable per extension with
  `MarkdownExtension`: tables, task lists, strikethrough, extended autolinks (`www.`, `http(s)://`,
  `ftp://`, email, `mailto:` and `xmpp:`) and footnotes. The GFM specification's extension examples
  and cmark-gfm's extension tests run on every platform.
- `IncrementalMarkdownParser` for text that grows over time (streamed responses, live editing): completed top-level blocks are parsed once and keep
  their instances; only the open end of the document is parsed again on each update, so the cost
  per update does not grow with the document. The finished document is always identical to a
  one-shot parse, verified by streaming every specification example character by character, in
  random chunks, with random edits, and with fuzzed input.
- `StreamingPolicy.OPTIMISTIC` (default) renders unfinished emphasis, code spans and links in their
  likely final form and holds back half-written block markers and table headers to avoid flicker;
  `StreamingPolicy.STRICT` parses the text exactly as written at every step.
- JVM parser benchmarks (kotlinx-benchmark) with a recorded baseline.
- `composdown-compose`: `Composdown` composables for static text, a `ComposdownState` (parsing on a
  background dispatcher) or a parsed document; `composdownItems` to render a document's blocks as
  `LazyColumn` items; Material 3 based `ComposdownTheme`; replaceable block rendering with
  `ComposdownComponents`; pluggable `ImageRenderer`; safe default link handling; text selection;
  heading, link, task and table semantics; per-block right-to-left layout.
- Compose UI tests and light and dark screenshot tests (Roborazzi) on Desktop, verified in CI.
- `composdown-coil`: `CoilImageRenderer`, which reserves space while images load, remembers their
  sizes so they do not resize again, and loads only HTTPS images by default.
- Sample app for Android, iOS and Desktop: a simulated streaming chat and a showcase of every element.
- `MarkdownExtension.MATH`: inline and display math (`$...$`, `$$...$$`, `\(...\)`, `\[...\]`) and
  math blocks (`$$` or `\[` lines and ```` ```math ```` code blocks), with rules that keep amounts such
  as "$5 and $10" as text. Rendered as TeX source by default, with a `mathBlock` component slot.
- `CodeHighlighter` for syntax-colored code blocks, and `composdown-highlight` with
  `HighlightsCodeHighlighter`, based on the pure Kotlin Highlights library.
- GitHub alerts (`> [!NOTE]`, `[!TIP]`, `[!IMPORTANT]`, `[!WARNING]`, `[!CAUTION]`) as an opt-in
  extension.
- Protection against hostile input: parsing runs in linear time on known pathological inputs, and
  block quotes, lists and inline elements nested deeper than 100 levels are flattened instead of
  exhausting the stack.

- Documentation: user guides in `docs/` (getting started, rendering, live content, customization,
  parser, accessibility, compatibility, architecture), a security model, and contribution guidelines.

- README images (overview, streaming animation, customization, right-to-left), rendered by Composdown
  itself with `tools/screenshots`, and a project logo.
- Baseline Profiles in the Android artifacts of `composdown-core` and `composdown-compose`, merged
  automatically into applications' profiles.
- Android Macrobenchmarks of startup, scrolling and streaming in the sample app, a Baseline Profile
  generator, and a workflow that runs them on an emulator.
- Publishing to Maven Central as `io.github.springmusk026:composdown-*`, with sources, signed
  artifacts and an API reference generated by Dokka; a release workflow driven by version tags.
- `MarkdownDocument.toHtml()` renders HTML: safe for untrusted input by default (raw HTML escaped,
  dangerous link schemes removed), with options for raw HTML, heading ids and soft breaks, and
  `HtmlOptions.CommonMark` for output identical to the reference implementations.
- `MarkdownDocument.headings()` with GitHub-compatible anchors, `plainText()` for whole documents, and
  `allBlocks()` and `allInlines()` to traverse every node of a document.
- Links to a heading of the document (`[Installation](#installation)`) scroll to it in `Composdown`.

### Fixed

- Right-aligned and centered table columns rendered their cells left-aligned when the column was wider
  than the cell's text.

### Changed

- The title of an alert sits closer to its content.
